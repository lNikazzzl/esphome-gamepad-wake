# DualSense Wake

**Русский** · [English](README.en.md)

Нажмите PS на геймпаде, привязанном к **выключенному** компьютеру, — и в Home Assistant придёт событие. Дальше что угодно: разбудить ПК по Wake-on-LAN, включить телевизор и т.д. Геймпад остаётся привязан к компу.

Проверено с DualSense. Должно работать с DualShock 4 и другими геймпадами, которые переподключаются к компу по Bluetooth Classic; BLE-геймпады (например, Xbox Series) не подойдут.

## Как это работает

При нажатии PS геймпад вызывает Bluetooth-адрес своего компа. ESP32 берёт этот адрес, получает запрос на подключение, отклоняет его до привязки и авторизации и отправляет событие. Пока комп включён, ESP32 молчит, и геймпад подключается к компу как обычно.

## Что нужно

- **Оригинальный ESP32** (WROOM-32, DevKit). У ESP32-S2/S3/C3/C6 нет Bluetooth Classic.
- Home Assistant с интеграцией ESPHome.

## Установка

1. Откройте **https://lnikazzzl.github.io/esphome-gamepad-wake/** в Chrome или Edge, подключите ESP32 по USB, нажмите *Install* и введите Wi-Fi.
   Не ввели Wi-Fi? Подключитесь к открытой точке доступа `dualsense-wake-xxxxxx` и задайте сеть там.
2. Home Assistant найдёт устройство — добавьте его (ключ шифрования не нужен).
3. Впишите **PC Bluetooth MAC**. ESP32 перезагрузится, и **ESP Bluetooth Address** должен показать тот же адрес.
   - Windows: Диспетчер устройств → Bluetooth → ваш адаптер → Свойства → Сведения → *Адрес устройства Bluetooth*
   - Linux: `bluetoothctl list` · macOS: Информация о системе → Bluetooth
4. Рекомендуется: впишите **PC IP** и разрешите на компе ответ на пинг (Windows: `netsh advfirewall firewall add rule name="ICMP echo" protocol=icmpv4:8,any dir=in action=allow`).
5. Создайте автоматизацию с триггером **PS Button**, например *Wake on LAN: отправить magic packet* на комп.

## Сущности

| Сущность | |
|---|---|
| **PS Button** | Событие `press` — триггер для автоматизаций |
| **Enabled** | Общий выключатель |
| **PC Bluetooth MAC** | За какой адрес отвечать; после изменения ESP32 перезагружается |
| **PC IP** | Необязательно; пока комп отвечает на пинг, ESP32 молчит |
| **Pause After Press** | Сколько молчать после нажатия, чтобы следующее нажатие дошло до загрузившегося компа (по умолчанию 90 с, 0 — выкл) |
| **Ignore After PC Off** | Сколько молчать после выключения компа, пока геймпад ещё пытается переподключиться (по умолчанию 30 с, нужен PC IP) |
| **Any Device Triggers** | Выкл: событие только от геймпадов. Другие привязанные устройства (наушники, мыши) отклоняются молча |
| **Listening** | Отвечает ли ESP32 сейчас за комп |
| **PC Online** · **Last Device** · **ESP Bluetooth Address** | Диагностика |
| **Restart** | Перезагрузить ESP32 |

ESP32 слушает, только если *Enabled* включён, MAC задан, не идёт пауза и — если задан *PC IP* — комп офлайн, а Wi-Fi подключён.

**Без PC IP** после паузы ESP32 снова начинает слушать, даже если комп включён, и может перехватить следующее переподключение геймпада — нажмите PS ещё раз. Чтобы этого не было, задайте PC IP или выключайте *Enabled* по любому датчику «комп включён» (HASS.Agent, розетка с замером мощности).

## Ограничения

- Один ESP32 отвечает за один комп.
- Если комп спит с включённым пробуждением по Bluetooth, ответить могут оба. Задайте PC IP или выключайте *Enabled*, пока комп спит.
- Wi-Fi и Bluetooth делят одно радио ESP32; при слабом Wi-Fi нажатие может потеряться.
- API, OTA и резервная точка доступа без пароля — ради работы «из коробки». Любой в вашей сети может перепрошить устройство. Если это важно, добавьте `api: encryption` и пароль OTA.
- Конфиг для ESPHome Dashboard берёт компонент из ветки `main`.

## Сборка

`esphome run dualsense-wake.factory.yaml` собирает прошивку с локальным компонентом. Чтобы опубликовать форк: замените `lNikazzzl/esphome-gamepad-wake` (и адрес `lnikazzzl.github.io`) во всех файлах, включите *Settings → Pages → Source: GitHub Actions*, запушьте в `main` (создастся черновик релиза и соберётся прошивка), затем запустите *Actions → Release*.
