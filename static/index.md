# Install

Connect an original ESP32 (WROOM-32, **not** S2/S3/C3/C6) over USB and click the button. You can enter Wi-Fi right after flashing.

<esp-web-install-button manifest="firmware/dualsense-wake.manifest.json"></esp-web-install-button>

<script type="module" src="https://unpkg.com/esp-web-tools@10/dist/web/install-button.js?module"></script>

Then add the device in Home Assistant and set **PC Bluetooth MAC**. See the [README](https://github.com/lNikazzzl/esphome-gamepad-wake#readme).
